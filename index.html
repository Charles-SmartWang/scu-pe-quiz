使用说明

怎么打开

  • 电脑：直接双击本文件，用 Chrome / Edge 打开。
  • 手机：把文件发到手机（QQ / 微信 / 邮件），点“用其他应用打开”→ 选浏览器。
  • 文件可以改名、复制、转发给同学，不需要安装任何东西。

四个功能

  • 刷题：按题型 / 项目筛选，点选项立即判分，答错自动进错题本。
  • 查题：输入题干里的几个关键词，直接看答案和解析（选项）。
  • 模拟考试：按真实考试结构抽 50 题（判断 22 + 单选 28），60 分钟，满分 100。
  • 错题本：自动收集答错的题，可随时重看、移除。

注意

  • 题库共 6067 题（判断 3153 / 单选 2488 / 多选 426），答案是题库原答案，仅供参考。
  • 题库里同一题干可能有多个版本（选项不同、答案字母不同），遇到时页面会提示，以本题选项为准。
  • 错题本存在本机浏览器里，换设备 / 清缓存会丢失。
